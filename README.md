# EstoqueControl

Atividade complementar - componente curricular **Programação Web BackEnd** do Curso Técnico de Desenvolvimento de Sistemas.

Instalação:

No application.properties ative ou desative os ambientes test/production conforme necessidade.

** Atenção: **

Apenas um dos ambiententes devem estar ativos.

```

# Definição de ambiente de execução
# ---------------------------------------

spring.profiles.active=test
#spring.profiles.active=prod
#spring.profiles.active=prodVercel

```
